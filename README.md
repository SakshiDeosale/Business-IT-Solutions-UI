# 🚀 Business Solutions Website

A modern, responsive **Business & IT Solutions Website** built using HTML and CSS. This project showcases services, portfolio, and company information in a clean and interactive UI.

---

## 📌 Features

* 🌐 Fully responsive design
* 📱 Mobile-friendly navigation (hamburger menu)
* 🎯 Smooth scrolling between sections
* 💼 Services section with structured cards
* 🔄 Interactive portfolio with flip-card animations
* 👨‍💼 About section with team details
* 📞 Contact form layout
* 🎨 Clean and modern UI with CSS styling

---

## 🛠️ Tech Stack

* **HTML5**
* **CSS3**
* **Font Awesome (Icons)**
* **Google Fonts (Poppins)**

## 🚀 Getting Started

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/business-solutions-website.git
   ```

2. Navigate to the project folder:

   ```bash
   cd business-solutions-website
   ```

3. Open `index.html` in your browser.
